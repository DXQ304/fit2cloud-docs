## 1 新建回款计划
:::note

在左侧菜单点击【合同】，顶部选择回款计划标签，进入回款计划管理页面。
:::

![创建回款计划](/img/cordys/user_manual/paymentplancraet2.png)

:::note

用户可以「新建回款计划」或「导出回款计划」。
:::

![回款计划列表](/img/cordys/user_manual/paymentlist2.png)

:::note

**提示**：回款计划表单可以根据公司业务特性在表单设置中进行自定义。
:::

![回款计划配置.png](/img/cordys/user_manual/paymentseetings2.png)
