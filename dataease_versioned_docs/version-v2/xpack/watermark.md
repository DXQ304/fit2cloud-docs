---
title: 水印管理
---

:::note

支持基本的水印设置，支持设置水印颜色、字号、间距，仅影响所有可以看到仪表板和数据大屏的地方；  
内容支持设置：

- 自定义公式（可选择以下内容自由组合）
- 账号
- 昵称
- IP
- 当前时间
:::

<img alt="水印管理" src="/img/dataease-v2/xpack/水印管理.png" width="900" style={{maxWidth:'100%', height:'auto'}}/>

:::note

自定义公式可参考系统提示的参数。
:::

<img alt="水印管理" src="/img/dataease-v2/xpack/水印参数.png" width="900" style={{maxWidth:'100%', height:'auto'}}/>

:::note

完成设置后可点击预览进行确认。
:::

<img alt="水印管理" src="/img/dataease-v2/xpack/水印预览.png" width="900" style={{maxWidth:'100%', height:'auto'}}/>

:::note

若开启允许仪表板和数据大屏单独打开或者关闭水印，则在仪表板和数据大屏编辑界面中可选择水印开关。
:::
